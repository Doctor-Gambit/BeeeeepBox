# BeeeeepBox

BeeeeepBox is a mod of the online tool BeepBox for sketching melodies.
Try it out [here](https://www.beepbox.co)!

BeepBox has a bar limit of 128, but in this small mod, BeeeeepBox has a limit of 1028 bars instead!

BeeeeepBox is a small mod, and is not originally made by myself. It was developed by John Nesky. If you find BeepBox or BeeeeepBox useful, please consider sending any gratitude via PayPal to him!
